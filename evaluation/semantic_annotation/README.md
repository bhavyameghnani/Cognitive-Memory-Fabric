# Semantic annotation evaluation package (preparation phase)

Nothing here is ground truth yet. Generated by `scripts/semantic_eval.py build` (deterministic; safe to regenerate). Not part of the dataset: it is kept out of `datasets/` and never read by ingestion.

| File | Purpose | Who reads it |
|---|---|---|
| `review_sheet_blind.md` | Source text and context for 202 items plus 20 containers. **No system labels.** | Human annotators |
| `annotation_template.csv`, `segmentation_template.csv` | Blank expected-annotation forms (separate from system output) | Human annotators fill |
| `label_definitions.md`, `labels.json` | Permitted values and definitions | Annotators, scorer |
| `items.jsonl`, `segmentation_items.jsonl` | Analyst view: source, parsed text, provenance, system labels, relations, context, strata | Analysts, scorer |
| `known_defects.md`, `known_defects.json` | 13 defect groups, 37 cases, reproduced from the database | Reviewers |
| `diagnostics.json` | Metrics computable without human labels | Reviewers |
| `sample_manifest.json` | Sample composition and quotas | Reviewers |
| `methodology.md`, `gap_analysis.md` | Metric definitions; fix priorities | Reviewers (hand-written, not regenerated) |
