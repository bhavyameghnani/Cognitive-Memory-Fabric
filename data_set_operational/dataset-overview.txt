•⁠  ⁠client_financial_profiles.csv – Stores each client's financial profile, income, expenses, risk category and retirement details so tools can understand their financial circumstances.

•⁠  ⁠client_expense_history.csv – Stores historical spending changes so tools can calculate liquidity and expenses for a particular date.

•⁠  ⁠portfolio_accounts.csv – Stores client investment accounts and access restrictions so calculations include only eligible, investable accounts.

•⁠  ⁠portfolio_holdings.csv – Stores current investments, quantities, values, issuers and asset classes so tools can retrieve portfolios and calculate allocation and concentration.

•⁠  ⁠portfolio_snapshots.csv – Stores monthly portfolio valuations from January to June so tools can compare portfolios and analyse historical changes.

•⁠  ⁠portfolio_transactions.csv – Stores buys, sells, contributions, withdrawals and other transactions so portfolio changes can be traced and returns calculated appropriately.

•⁠  ⁠financial_goals.csv – Stores versioned financial goals and their timelines so tools can calculate goal-funding gaps as of a particular date.

•⁠  ⁠liabilities.csv – Stores mortgages, loans and recurring financial obligations so tools can account for a client's liabilities.

•⁠  ⁠data_evidence_links.csv – Links financial facts to their original conversation turns or design-document evidence so tools can trace where information came from.

•⁠  ⁠ref_instruments.csv – Stores the fictional investment instrument catalogue so holdings refer to consistent instrument definitions.

•⁠  ⁠ref_asset_classes.csv – Defines asset-class categories so portfolio allocation and classification remain consistent.

•⁠  ⁠ref_liquidity_categories.csv – Defines liquidity categories and their rankings so tools apply a common liquidity classification.

•⁠  ⁠ref_market_path.csv – Stores monthly equity and bond market returns so historical instrument prices can be generated consistently and reproducibly.
